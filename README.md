# Shutdown Timer

A Windows desktop application that schedules an automatic system shutdown after a user-defined countdown period. The countdown is displayed on a draggable, always-on-top floating overlay window.

## Purpose

This project provides a lightweight graphical utility for users who need to schedule a Windows shutdown after a specific duration — for example, leaving a download running overnight or watching a movie before the PC turns off automatically. It is intended for Windows users who prefer a visual countdown with customization options over the built-in `shutdown /s /t <seconds>` command.

## Features

- **Countdown Input**: Set days, hours, minutes, and seconds via separate text fields with real-time input validation.
- **Floating Overlay Window**: An always-on-top, draggable overlay displays the remaining time.
- **Countdown Threading**: The countdown runs in a background daemon thread to keep the UI responsive.
- **Pause / Resume**: Pause and resume the countdown without losing progress.
- **Cancel with Confirmation**: Cancel a running timer after a yes/no confirmation dialog.
- **10-Second Shutdown Warning**: A popup warning appears 10 seconds before shutdown with a cancel button.
- **Automatic Windows Shutdown**: Executes `shutdown /s /t 5` on timer completion.
- **Customizable Overlay**: Change font family, font size, text color, background color, and opacity.
- **Dynamic Size Mode**: When enabled, the overlay auto-fits its size to the current countdown text. When disabled, the overlay is manually resizable via right-click drag.
- **Configuration Persistence**: Saves and loads overlay appearance settings (font, colors, opacity, position, size) and the last used timer values to/from a JSON file.
- **Save-to-Config Toggle**: Optional toggle to enable/disable saving settings to `config_for_shutdown_timer.json`.
- **Overlay Toggle**: Checkbox to show or hide the floating overlay.
- **Keyboard Shortcuts**: `Ctrl+S` start, `Ctrl+P` pause/resume, `Ctrl+C` cancel, `Esc` exit.
- **DPI Awareness**: Sets process DPI awareness on Windows via `ctypes.windll.shcore.SetProcessDpiAwareness`.
- **Executable Build**: Bundled into a single `.exe` via PyInstaller. A batch script automates the build process.

### Request / Data Flow

1. User enters time values → input fields validated to accept only non-negative integers with per-field limits (days ≤ 365, hours ≤ 23, minutes/seconds ≤ 59).
2. User clicks "Start Timer" → `start_timer()` validates total seconds > 0, then spawns a daemon thread running `countdown_task()`.
3. The background thread loops every second: calculates elapsed time, decrements `remaining_time`, updates `overlay_time_var` (which propagates to the overlay label via Tkinter's `StringVar`).
4. When `remaining_time` drops to ≤ 10 seconds and shutdown has not yet been scheduled, `show_shutdown_warning()` creates a modal popup with a "Cancel Shutdown" button.
5. When `remaining_time` reaches 0, `perform_shutdown()` calls `os.system("shutdown /s /t 5")` which schedules Windows shutdown with a 5-second grace period.
6. Pause/Resume toggles `is_paused` and adjusts `start_time` to account for paused duration.
7. Cancel sets `is_running = False`, resets UI, and clears overlay.

### State Management

Application state is held in instance attributes of `ShutdownTimerApp`:

| Attribute          | Type      | Purpose                                  |
|-------------------|-----------|------------------------------------------|
| `is_running`      | bool      | Whether a countdown is active            |
| `is_paused`       | bool      | Whether the active countdown is paused   |
| `remaining_time`  | float     | Seconds remaining before shutdown        |
| `start_time`      | float     | `time.time()` when the current segment started |
| `pause_time`      | float     | `time.time()` when pause was initiated   |
| `shutdown_scheduled` | bool   | Whether the 10-second warning has fired  |

The overlay position/size and all customization settings are persisted to `config_for_shutdown_timer.json` (if the save toggle is enabled).

### Error Handling

- Input validation rejects non-digit characters and out-of-range values.
- `start_timer()` prevents starting a second timer while one is already running.
- `cancel_timer()` prompts for confirmation via `messagebox.askyesno`.
- `on_closing()` warns if a timer is running before closing.
- The countdown thread catches exceptions and posts error messages to the status label via `root.after()`.
- `perform_shutdown()` is wrapped in try/except.
- Config load/save operations are wrapped in try/except, falling back to defaults.
- Icon loading gracefully skips if `assets/icon.ico` is not found.
- DPI awareness call is wrapped in try/except (may fail on some Windows versions).

## How It Works

1. **Launch**: The application starts, loads saved configuration (or defaults), creates the main window and the floating overlay (initially hidden), and restores the last used timer values into the input fields.
2. **Set Timer**: The user enters days, hours, minutes, and seconds. Input is validated in real time — only non-negative integers are accepted, and per-field caps are enforced (e.g., hours ≤ 23).
3. **Start**: Clicking "Start Timer" (or pressing `Ctrl+S`) calculates the total seconds. If valid and no timer is running, a daemon thread is spawned.
4. **Countdown**: The thread runs a loop: it calculates elapsed wall-clock time, subtracts it from the remaining time, updates the overlay label via a Tkinter `StringVar`, then sleeps for 1 second. If dynamic sizing is enabled, the overlay window resizes to fit the current text exactly.
5. **Pause**: Clicking "Pause" records the current time as the pause moment. Clicking "Resume" adjusts the start time so the elapsed calculation resumes correctly.
6. **Warning**: When 10 seconds remain, a centered, always-on-top popup appears with a "Cancel Shutdown" button. If the user cancels, the timer stops and the shutdown does not occur.
7. **Shutdown**: When the countdown reaches zero, `os.system("shutdown /s /t 5")` is called, scheduling a Windows shutdown with a 5-second grace period. The application's config is saved just before the shutdown command.
8. **Customization**: The user can change the overlay's font (family + size via a dedicated dialog), text color, background color (both via the system color picker), and opacity (via a slider). Changes apply in real time to the overlay and are optionally persisted.
9. **Exit**: Closing the main window saves the overlay position, size, and current timer values to config, destroys both windows, and exits.
